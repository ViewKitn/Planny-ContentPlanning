# เริ่มจากเครื่องมือส่วนตัวสำหรับครีเอเตอร์หนึ่งคน

รุ่นแรกของ Planny เน้นครีเอเตอร์หนึ่งคนที่ดูแลหนึ่งเพจ จึงมีพื้นที่งานเดียวและไม่มีระบบบัญชี แทนการแยกหลาย Brand ตาม ADR-0002 เพื่อเน้นเส้นทางจัดการคอนเทนต์ให้สมบูรณ์ก่อน ระบบสมัคร/เข้าสู่ระบบด้วยอีเมลและรหัสผ่านพร้อมกู้รหัสผ่านจะเพิ่มใน MVP ภายหลัง; ก่อนเปิดให้หลายผู้ใช้ต้องกำหนดความเป็นเจ้าของและการแยกข้อมูล
