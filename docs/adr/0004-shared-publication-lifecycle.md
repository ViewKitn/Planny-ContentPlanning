# ใช้วงจรเผยแพร่ร่วมกันทุกแพลตฟอร์ม

ครีเอเตอร์เป้าหมายมักเผยแพร่พร้อมกันทุกแพลตฟอร์ม จึงให้ Content มีสถานะ กำหนดเผยแพร่ และเวลาเผยแพร่จริงชุดเดียว แทน Publication แยกตาม ADR-0001 โดยยังแยก caption และลิงก์รายแพลตฟอร์ม Published หมายถึงเผยแพร่ครบปลายทางที่เลือก; หากยังไม่ครบให้คง Planned วิธีนี้ลดขั้นตอนจัดการงาน แต่ไม่รองรับสถานะหรือกำหนดเผยแพร่อิสระต่อแพลตฟอร์ม และเวลาเผยแพร่จริงเป็นค่าร่วมที่ผู้ใช้บันทึก
